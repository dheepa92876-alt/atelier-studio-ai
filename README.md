# 🎨 Atelier - AI Image Generation Studio

Atelier is an AI-powered web application that transforms text prompts into unique, high-quality images using modern generative AI models. Designed for creators, designers, and AI enthusiasts, Atelier provides an intuitive interface with advanced customization options to bring ideas to life.

## 🌐 Live Demo

**Visit the application:**
https://atelierstudioai.lovable.app/

## 🚀 Features

* 📝 Text-to-Image Generation
* 💡 Prompt Suggestions
* 🚫 Negative Prompt Support
* 🎛️ Advanced Generation Settings
* 🤖 Multiple AI Model Options
* 🖼️ Image Preview & Download
* 📱 Responsive User Interface
* ⚡ Fast and Seamless User Experience

## 🛠️ Tech Stack

### Frontend

* React

* Tailwind CSS

### Backend & AI Integration

* Generative AI APIs

### Development Tools

* Git

## 📸 Project Overview

Atelier enables users to convert natural language descriptions into AI-generated artwork. By leveraging advanced image generation models, users can experiment with different prompts, styles, and generation parameters to create unique visuals for creative and professional use cases.

## ✨ Key Highlights

* User-friendly design for seamless image creation
* Customizable prompts and generation controls
* Modern responsive interface
* Real-time AI-powered image generation
* Suitable for artists, content creators, and developers

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/dheepa92876-alt/atelier-studio-ai.git
```

Navigate to the project directory:

```bash
cd atelier-studio-ai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
